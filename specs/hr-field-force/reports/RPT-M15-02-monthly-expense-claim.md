# RPT-M15-02 Monthly Employee Expense Claim (Crystal PDF/viewer)

- **List pages:** PAGE-623 `Reports_UI/EmpMonthlyExpenseRpt.aspx` (single employee: employee, month, year -> `CmnCrystaltoView.GetMonthlyExpenseList` -> `sp_Get_EmployyeMonthlyExpense`; Excel export via HTML), PAGE-624 `EmpMonthlyExpenseRptMultiple.aspx` (multi-select employees: filters role, employee status (`PM.EmployeeStatus`), month/year -> `EmployeeInformationDaL.GetEmployeeInformationListForReport` -> `sp_RPT_MonthlyExpense(@Parm,@Month,@Year)` (`EmployeeInformationDaL.cs`), territory code per row via `sp_Get_TerritoryCodeByRoleTypeEmpId`). Checked rows -> comma list of `EmpInfoId`; "Export" opens a popup.
- **Viewer:** PAGE-628 `SInventory_RPTVIEW/EmployeeExpenseReportViewer.aspx?rptType=<id[,id...]>&Month=&Year=&fType=<Crys|other>`; loads `Solution.Web/Reports/CrystalReports/crpEmpExpense.rpt`, `SetDataSource` of DataSet tables `dtExpense`, `dtTotal`, `dtAllowance`, `dtStationType`. `fType=="Crys"` -> Crystal viewer, else PDF export named `Monthly Expense Claim`.
- **SPs (`Library.DAL/MasterSetup_DAL/ExpenseDal.cs`):** `dtExpense` <- `sp_Get_MonthlyExpenseEmpWiseMaster_Final` (per employee, called per id for multi-select; columns `MainDate_, EmpInfoId, EmpMasterCode, EmpName, DesigName, BaseHQ, MarketCode, ZoneCode, MonthYear, DAdate, MarketName, TourType, daAmount(int), AllowedMileageInKM, mileageAmount, expenseAmount, totalAmount`); `dtTotal` <- `sp_Get_MonthlyExpenseEmpWiseTotal`; `dtAllowance` <- `sp_Webapi_Get_EmpAllawance_MonthYear`; `dtStationType` <- `sp_Webapi_Get_TourPlanBalanceEmp`. Note `dtTotal/dtAllowance/dtStationType` are fetched with the raw comma list `EmpId` (behaviour for multiple ids UNKNOWN).
- **Calculation:** all totals inside SPs (UNKNOWN). `daAmount` cast to `int` (rounding of decimals in the multi-employee path: `Convert.ToInt32(string)` throws for decimals such as "500.00" - INFERRED risk). Data errors swallowed by empty `catch`. (BR-M15-078, GAP-M15-024/025.)
- **Access:** no permission check; viewer accepts any employee id in the URL (IDOR).
