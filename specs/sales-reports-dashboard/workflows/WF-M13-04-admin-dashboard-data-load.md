# WF-M13-04 Admin dashboard data load and endpoint catalogue

_Module M13, reverse-engineered 2026-09-19 (documentation only). Confidence tags as in the page specs._

## Trigger and actors
After login `Login.aspx.cs:96` redirects to `Dashboard_UI/AdminDashboard.aspx` (main-dashboard users).

## Steps
1. `Page_Load` -> `UserPersmissionValidation` (BR-M13-015).
2. Browser `$(document).ready` (aspx:1461): `GetTotalData(1)` -> `GetTotalInfoByCurrentDate` (role-scoped KPI header, BR-M13-016) and 10 top-bar chart loaders + brand-wise order.
3. User changes filters -> `GetData(type)` builds SQL-fragment `param` (BR-M13-019) -> POST to the matching WebMethod -> `ChartDAL` -> SP -> `JsonConvert.SerializeObject(DataTable)` -> chart.
4. Multi-month endpoints call the SP per month and pivot in C# (BR-M13-017, BR-M13-020).
